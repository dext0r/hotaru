# Альтернативная прошивка eWeLink ZB-SW01 / ZB-SW02

Оригинальная прошивка обладает недостатками:

1. Выключатель без нейтрали, который умеет роутить - это плохая идея. Так никто не делает.
2. Если быстро щелкать в ZHA, то рано или поздно статус станет кривым. Возможно вызвано спамом Route Request запросами.
3. Не настраиваются интервалы репортов.

Для устранения этих недостатков можно использовать прошивку на базе PTVO. С ней выключатель начинает работать супер быстро и стабильно.

Внутри стоит модуль СС2530 / [SM015](https://github.com/CoolKit-Technologies/DevDocs/blob/master/Zigbee/SM-015应用指导.md). Пины DD/DC не в доступе. Нужно или выпаивать модуль целиком феном, или [подпаиваться](./PCB.jpg) напрямую к чипу (мой выбор). Можно использовать ESP8266 и <https://mt.xyzroe.cc>
